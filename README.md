Este projeto, desenvolvido durante o Bootcamp DIO + Reclame Aqui, trouxe práticas importantes para aplicar os conhecimentos
adquiridos nos módulos realizados até então.<br><br>

Além da construção da própria ferramenta, o projeto também permitiu trabalhar aspectos como atenção aos detalhes, organização
das informações e apresentação visual da planilha.<br><br>

O simulador permite, a partir de um aporte mensal, visualizar projeções de investimento para diferentes períodos: 2, 5, 10,
20 e 30 anos. <br>
O resultado também é influenciado pelo perfil do investidor, uma vez que cada perfil possui uma distribuição percentual 
diferente entre os investimentos. <br><br>

A função VF (Valor Futuro) é utilizada para calcular as projeções dos investimentos ao longo dos períodos apresentados, 
considerando o aporte e os parâmetros definidos na ferramenta. <br><br>

Já a função PROCV utiliza uma tabela de apoio para identificar o perfil de investidor selecionado e buscar os respectivos
percentuais de distribuição. Dessa forma, ao alterar o perfil, a ferramenta automaticamente modifica a porcentagem destinada
a cada tipo de investimento e, consequentemente, os valores projetados. <br><br>

Foram utilizados intervalos nomeados para facilitar a leitura e manutenção das fórmulas. <br><br>

O projeto possibilitou, portanto, aplicar funções financeiras e de busca do Excel em uma ferramenta interativa, relacionando
diferentes variáveis para apresentar cenários de investimento de forma visual e organizada. <br><br>

Em relação a planilha do expert apresentada, fiz pequenas mudanças como: <br>
Criação de um topo personalizado, desenvolvido especificamente para a minha versão da ferramenta; <br>
Alteração da paleta de cores utilizada na planilha; <br>
Personalização dos tipos de bordas e formatações; <br><br>
